# Content And Story Layer

The story layer defines what belongs to a run and what may vary.

## Story Dictionary

The story dictionary is seeded JSON. It defines:

- theme
- main counselor institutions
- configured threat
- delayed threat and entry turn
- hidden achievement unlock
- generation slack

Generation slack is explicit loose material the engine may draw from:

- prince names
- representative pools
- pressure seeds
- generated threat seeds
- place-name pools
- generation toggles

## Story Nodes

Story nodes are selectable story objects. They are broader than people.

Current story node types:

- people
- places
- logs
- threats
- achievements

Later story node types may include decrees, rumors, artifacts, institutions, factions, roads, laws, debts, and imported custom material.

## Characters

Characters are not the same thing as system nodes. A counselor can be:

- a person in scenes
- a source of logs and memory
- an interface to a system node

The institution remains the system node. The person is how the player touches it.
