# Simulation Theory

ACES values are internal pressure readings, not player-facing stats.

## Current ACES Profile

- legitimacy
- optionality
- reconstructability
- tension
- concentration
- adaptability
- participation
- conductance
- memory load

## Calibration

Internal values use a normalized 0-100 scale. Player-facing presentation should use qualitative language.

Suggested internal change magnitudes:

- minor cue: +/- 1
- meaningful log: +/- 2-4
- major event: +/- 5-8
- crisis: +/- 10-15

Different metrics should move at different speeds.

- Fast: tension, conductance distortion, visible participation.
- Medium: legitimacy, adaptability, optionality.
- Slow: concentration, reconstructability, memory load.

## Mutation Path

```text
Action or injector creates a log
-> proxy cards apply bounded structural effects
-> field generator propagates pressure
-> reader samples situated access
-> presenter reveals qualitative experience
```

The player should normally perceive pressure through scenes, contradictions, advisor framing, story nodes, and logs rather than raw numbers.
